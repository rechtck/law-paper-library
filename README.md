# 法学论文阅读库

为个人阅读服务，关注《中外法学》《法学研究》《中国法学》的民法、商法、网络治理及 AI 治理论文。优先从[阅读目录](阅读目录.md)进入，各标题链接到独立论文卡片。

## 数据源选择理由及简介

选择三本法学期刊，是为了持续跟踪民商法、网络治理和 AI 治理研究，服务个人检索、选读与引用。优先使用期刊自身的公开目录和摘要，便于核对作者、期次与来源；官网不可用时使用公共学术文献平台，并明确标注采集方式。

|期刊|本版实际来源|本版收录|
|---|---|---|
|《中国法学》|[杂志社第3期目录](https://clsjp.chinalaw.org.cn/portal/list/index.html?id=1926)、[第4期目录](https://clsjp.chinalaw.org.cn/portal/list/index.html?id=1934)|2026年第3、4期，共8篇|
|《法学研究》|[期刊官网](https://faxueyanjiu.ajcass.com/)|2026年第4期，共3篇|
|《中外法学》|[国家哲学社会科学文献中心](https://www.ncpssd.cn/journal/details?gch=81439X)|2026年第3期，共4篇|

数据源均为公开网站，不以微信公众号作为采集入口。本版共15个独立论文文件，其中8篇含原文摘要。

## 已实现

- 真实作者、论文题名、期刊期次、来源链接和可获得的页码；不脱敏。
- 中国法学公开摘要采集，保留原文表述；页面提供的 PDF 入口仅保存链接。
- 民法、商法、网络治理、AI 治理多标签初筛；分类依据仅为题名关键词，并非作者原关键词或全文内容判断。
- 每篇独立 Markdown 文件，开头含 YAML 元信息；另有 papers.json 供其他工具读取。
- 以期刊、年份、期号和规范化题名生成稳定标识，重复运行合并记录，保留首次发现时间。摘要缺失时保留已获取版本。
- 中国法学尝试从首页发现新期，兼顾本版第3、4期；法学研究读取官网当前期目录。

## 当前范围和限制

本版是小规模可用的阅读资料库，不是三刊全部年份或最新论文的完整数据库。阅读目录中的覆盖表为首版采集范围；后续运行的实际新增文章以 papers.json 和 last_run.json 为准。

《中国法学》摘要详情可读；《法学研究》本次摘要详情页要求浏览器验证，目录可读，故先保留题录和已有全文入口。《中外法学》官网返回 HTTP 567，改用国家哲学社会科学文献中心2026年第3期公开目录核验4篇相关文章；这些是核验后导入的记录，不是已经接通的自动采集源，最新期仍未确认。

不会用搜索引擎抓取时间代替论文发表日期。未知摘要、页码和日期留空，网页上传时间与论文出版时间分别记录。全文链接未逐一测试下载，也未下载论文 PDF。没有自动推断作者观点。

## 再次更新

在此目录运行：

```sh
python3 collect.py
```

只重建本地卡片、不联网：

```sh
python3 collect.py --offline
```

仅需 Python 3 标准库。网络异常逐项记录到 last_run.json，已有论文不会被删除；单条请求有超时，并设置请求间隔。网站改版可能需要调整提取规则。中外法学的核验导入记录位于 verified_import.json，可在核实后补充。

运行成功不代表全部来源成功：请同时查看 last_run.json 的 errors。未配置后台定时更新；再次运行由用户触发。

## 阅读笔记

papers/ 是自动生成区，再次运行会重建；个人笔记请放 notes/，按论文卡片中的 id 命名，更新不会修改该目录。

## 数据采集方法详细说明

1. `collect.py` 使用 Python 标准库请求公开网页，设置单次请求18秒超时和请求间隔。中国法学从首页发现新期，并访问首版配置的第3、4期；法学研究读取官网当前期目录。
2. 提取目录中的题名、作者、期次、页码（若有）、文章链接及页面提供的 PDF 链接。只识别法学研究实际目录条目，排除热门文章等侧栏内容。
3. 根据题名匹配民法、商法、网络治理和 AI 治理词表，允许一篇论文拥有多个标签。未命中词表的论文不进入本版，因此可能存在漏选，不能视为完整学术检索结果。
4. 对中国法学入选论文访问详情页，提取原摘要、关键词、出版日期和网页日期；无法获取的字段留空，不生成替代摘要。
5. 中外法学4条记录通过文献中心公开目录核验后写入 `verified_import.json`。这部分为人工核验导入，尚未实现自动更新。
6. 合并为 `papers.json`，生成 `papers/` 中的独立论文卡片、阅读目录和运行报告 `last_run.json`。每条记录保留来源及获取状态。

## 数据清洗方法详细说明

- 删除 HTML 标签、脚本、样式及注释，去掉导航等非论文信息；仅合并不影响内容的多余空白。
- 将题名、作者、年份、期号、页码、摘要和链接分字段保存，不修改作者观点。
- 用“期刊＋年份＋期号＋去空白题名”的 SHA-256 摘要生成标识；相同标识合并，保留首次发现时间。题名后续发生实质变化时仍可能产生新记录，需要人工复核。
- 将出版日期、网页日期和本地检查日期分别记录；未知值保存为 null。日期当前保留来源格式，未强行补出月份或日期。
- 主题标签为题名词表初筛，与作者关键词分开保存；缺少摘要的卡片明确显示“暂未获取”。
- 已检查15条记录标识唯一、作者题名非空、卡片存在、目录的本地链接有效，以及摘要未混入网站页脚。没有对所有原文下载链接逐一验证。

## 脱敏处理方法与适用口径

本项目不执行主体名称脱敏。所收录的作者及作者简介来自公开论文页面，保留这些信息用于文献引用、作者检索和回到原文；不生成匿名替代名称或身份映射表。该决定依据项目使用者明确提出的个人阅读需求，不应描述为“已完成脱敏”。

## 基础整理口径

仅移除网页导航及标签、合并多余空白、规范字段、去重。保留真实作者、原题名和原摘要，不为满足作业进行主体脱敏或论文改写。论文摘要不代表现行法结论。

论文及摘要的权利归原作者和相应权利人；此处提供个人阅读整理及来源链接，不将第三方论文内容声明为本项目原创或授予开源许可。未包含论文全文 PDF。
